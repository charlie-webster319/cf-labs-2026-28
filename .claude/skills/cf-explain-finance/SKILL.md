# Explain finance

Follow the repository's `AGENTS.md`. All paths below are relative to the repository root, regardless of where this skill is installed.

- Use `.assistant-resources/README.md` to locate the relevant lecture and key-concepts deck. Read the relevant `.tex` passages; consult the PDF when a diagram or slide layout matters. Read only the material needed for the question.
- Start with the economic intuition, then explain the formula and its symbols if useful. Connect the answer to the student's example or lab output. Keep the first explanation short and expand when asked.
- Preserve timing, units, return convention, compounding frequency and other stated assumptions. Lecture examples and labs can use different illustrative risk-free rates; Lab 2 uses 2%. Do not substitute one example's rate for another's.
- Attribute course material by lecture and slide title. Give a page number only after checking the PDF. Label new examples as illustrative. If the supplied materials do not cover a claim, say so rather than attributing it to the course. These files are a dated snapshot; Moodle may have newer versions.
- When a numerical example helps, check the arithmetic and explain what the result means for an investor or manager. Offer a small prediction or interpretation question when useful; do not withhold a requested explanation to force a quiz.
- A request for an explanation does not require changing a notebook, rewriting the slides or running the whole lab.
